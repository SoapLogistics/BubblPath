# Gabriel Learning and Assimilation Core

Gabriel Learning and Assimilation Core converts measured experience into validated,
versioned procedures that improve planning, execution, memory use, capability selection,
and agent routing.

## Modules

- **Ingestion**: Ingests raw outcomes from missions, tests, PR reviews, and deployments.
- **Normalization**: Standardizes raw ingested outcomes into a consistent format.
- **Lesson Extraction**: Extracts potential lesson candidates from normalized outcomes.
- **Validation**: Validates procedure candidates against historical data, lab experiments, or logical rules.
- **Promotion**: Promotes validated procedures into Mnemosyne or other durable storage.
- **Hypothesis Generation**: Generates testable hypotheses for procedure candidates.
- **Procedure Evolution**: Evaluates historical procedures and evolves them based on new evidence.
- **Agent Evaluation**: Evaluates agent performance based on ingested outcomes to update agent-performance profiles.
- **Feedback**: Coordinates feedback routing to the Planner and Agent Router.
